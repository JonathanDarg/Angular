# Angular Research & Learning Lab

Welcome to my Angular research repository! This workspace is dedicated to exploring, experimenting with, and mastering modern Angular architecture, component-driven design, reactive programming with RxJS, and enterprise-grade state management.

Whether it's leveraging the latest standalone components and signals, building robust reactive forms, or integrating with backend APIs, this repo serves as my centralized hub for frontend experimentation and best-practice implementation.

---

## Research Areas & Technologies

Here is the roadmap of Angular features and ecosystem tools explored in this repository:

| Category | Technology / Concept | Primary Use Case / Focus |
| :--- | :--- | :--- |
| **Core Architecture** | Standalone Components, Signals, Directives | Modern component lifecycle, fine-grained reactivity, modularity |
| **Reactive Programming** | RxJS, Observables, Operators | Handling asynchronous data streams, event handling, flattening maps |
| **State Management** | NgRx, Akita, Signals State | Managing global application state, immutability, side-effect management |
| **Routing & Navigation** | Angular Router, Lazy Loading, Guards | Feature route splitting, authentication guards, resolver patterns |
| **Forms & Validation** | Reactive Forms, Custom Validators | Dynamic form generation, robust client-side validation logic |
| **Testing & Quality** | Jasmine, Karma, Playwright, Cypress | Unit testing components/services, end-to-end (E2E) testing |
