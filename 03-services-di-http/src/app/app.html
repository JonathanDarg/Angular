1. Services

A service is a class for logic or data that several components share. Components ask for it instead of creating it themselves.

2. inject()

5. resource()

resource() loads async data as signals. When a signal in params changes, it reloads automatically. Here the loader uses the browser's fetch().

6. httpResource()

httpResource() is a resource built on HttpClient. You give it a function that returns a URL; when signals in that function change, it fetches again. Much less code than section 5.
